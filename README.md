# Todo List App

A simple Todo List application built with HTML, CSS, and JavaScript.

## Features
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Simple and clean UI

## Technologies Used
- HTML5
- CSS3
- JavaScript (DOM manipulation)

## Project Purpose
This project was built to practice basic front-end development skills and JavaScript logic.
